# v2.17.21 — Skill/Tool `run_vqcc_chain`: la cadena completa en una llamada

La integración MORPH/JSON/orquestador v2.17.18 estaba medida y pasando
en Kaggle (kernel 146280589: 364 passed, 0 failed). Esta versión la
convierte en Skill/Tool del repo: una sola llamada corre la cadena
completa — directiva JSON → orquestador → túnel MORPH → pipeline →
verificador oficial (con veto) — y devuelve un solo veredicto.

## Lo que quedó

- **Tool `run_vqcc_chain`** (`auto_mvp/operations.py`, operación 13
  del registro `OPERATIONS`): plan por defecto
  `[tunnel, proxy, gate, verify, compile, observe]` — verify ANTES
  de compile, así el veto oficial bloquea la compilación. Si la
  config trae `steps`, esos mandan y el orden queda registrado en
  `plan_order` + `verify_before_compile`.
- **Veredictos (8):** `PASS_OFICIAL` (promovido + oficial completo
  ok), `PASS_PARCIAL` (promovido + oficial parcial ok — dominio
  completo a 8 shots/x, como los kernels v5/v6), `PASS_LOCAL`
  (promovido, solo verificación local, NO oficial), `LOCAL_FALLO`
  (promovido pero la verificación local falló; lo local no veta),
  `PASS_SIN_VERIFY` (promovido, el plan no tenía paso verify),
  `VETO` (oficial FAIL → no se promueve ni compila),
  `VETO_SIN_VERIFICADOR` (veto fail-closed: falta el artefacto o el
  verificador no pudo correr), `RECHAZADO` (nada pasó proxy/puerta).
  Las directivas no parseadas nunca se descartan: quedan en
  `unparsed` con su motivo.
- **Cableado en los 4 lugares de la convención** (`skills/auto-mvp-vqcc/`):
  `operations.py` + `OPERATIONS`, `tools.py` (función Python),
  `functions.json` (esquema, requerido: `candidates`), `mcp_server.py`
  (entrada en TOOLS). El README documenta las 13 operaciones (la
  lista del test `test_skill_files_and_readme` ahora incluye
  `run_vqcc_chain`).
- **La Skill (SKILL.md) vive en las custom skills de Muse**
  (`cadena-vqcc`), NO en el repo: el test `test_skill_files_and_readme`
  exige que el README sea el único markdown del repo y que no haya
  SKILL.md en `skills/auto-mvp-vqcc/`. El README del repo documenta
  la operación; la SKILL.md de Muse documenta cómo invocarla.

## Cambios de soporte

- `auto_mvp/orchestrator.py`: el paso verify lee `verify_shots_per_x` /
  `verify_num_shots` / `verify_max_x` del candidato y los pasa a
  `verify_circuit_file`; el trace de verify registra `S` y `metrics`
  (ramas oficial y local). **Compatibilidad:** los overrides solo se
  pasan si el candidato los fija (si no, la llamada es
  `verify_circuit_file(path, task)`); así un verificador o un doble
  de test con la firma `(path, task)` sigue funcionando — el test H14
  (`test_h14_oficial_fail_veta_y_oficial_pass_promueve`, cuyo doble
  es un lambda de 2 argumentos) lo exige.
- `tests/test_auto_mvp_v070.py`: las tres listas que fijan las
  operaciones de la skill pasan de 12 a 13
  (`test_skill_files_and_readme`, `test_mcp_server_roundtrip`,
  `test_functions_json_schema`); `run_vqcc_chain` queda en la posición
  4 (tras `run_orchestrator`) en `functions.json`, `mcp_server.py`,
  `tools.py`, `OPERATIONS` y el README, en el mismo orden.
- `auto_mvp/vqcc/verify.py`: `verify_circuit_file` acepta `max_x`
  (pasa `--max-x`; dominio completo solo si shots en (None, 64) y
  max_x es None). Resolutor Kaggle `_kaggle_circuit_verifier(task)`:
  en Kaggle usa `sys.executable` + el verificador del dataset
  (`verifiers/<task>/verify_submission_<task>.py`) + PYTHONPATH al
  directorio del `kickmix.so` del dataset; si no está disponible,
  `verified=False, verified_by="none"` (fail-closed). **Bug
  corregido:** `verify_circuit_file` parseaba solo la ÚLTIMA línea
  de stdout como JSON, pero los verificadores oficiales imprimen
  JSON multilínea con indent=2 (la última línea es `}`) → todo
  verify oficial se leía como FAIL. Ahora parsea el stdout completo.
  Comportamiento local sin cambios (venv + competition-verifiers).
- Versión 2.17.19 -> 2.17.21 (`auto_mvp/__init__.py`, `pyproject.toml`).
  (La 2.17.19 del remoto corrigió las 6 expectativas viejas de la
  validación v2.17.17 v2; esta versión se construye sobre ella.)
